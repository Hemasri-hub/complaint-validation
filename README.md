# AI-Based Customer Complaint Management System

A full-stack complaint management application for e-commerce teams, built with React, Vite, Flask, SQLite, JWT authentication, and optional Google Gemini analysis.

## Project status

Initial project setup is in progress. The application will include customer registration and login, complaint submission and tracking, administrator complaint management, analytics, and AI-assisted complaint analysis. Gemini integration is optional at runtime; the application remains usable with local rule-based analysis when no API key is configured.
